Charybdis Mini layers

Every key on all five layers, labelled with the character it actually types. Labels assume the OS keyboard layout is French AZERTY (PC), so the sent keycode (small text) differs from the printed glyph. A small corner symbol shows the Shift output.

The keyboard detects macOS or Windows when you plug it in. On Windows, Cmd and Ctrl swap places and a few shortcuts change. Pick a system to see its labels:

Dashed keys are transparent: they fall through to the layer underneath (usually the base layer). The dark key on each layer is the thumb you are holding to get there.

Shows the Vial firmware layout (charybdis-mini/vial/keymap.c). After changing keys in Vial, save the layout as a .vil file and run python update_layers.py file.vil to refresh this page.
